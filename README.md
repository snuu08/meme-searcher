# Meme Searcher

YouTube, TikTok, Instagram 공식 API를 사용해 지금 어떤 밈이 뜨고 있는지 빠르게 확인하고 검색하는 MVP입니다.

국가는 비교가 아니라 필터입니다. 검색은 항상 전체 데이터를 대상으로 합니다.

## 실행 (권장)

API 키는 브라우저에 넣지 않습니다. Node 서버로 실행하세요.

1. 의존성 설치

```bash
npm install
```

2. 환경 변수 파일 만들기

Windows:

```bash
copy .env.example .env
```

macOS / Linux:

```bash
cp .env.example .env
```

3. `.env`에 가진 키만 입력합니다. 비워 두면 Demo 데이터로 화면이 유지됩니다.

```
YOUTUBE_API_KEY=
TIKTOK_CLIENT_KEY=
TIKTOK_CLIENT_SECRET=
TIKTOK_RESEARCH_ENABLED=false
INSTAGRAM_ACCESS_TOKEN=
INSTAGRAM_IG_USER_ID=
META_GRAPH_VERSION=v23.0
CACHE_MINUTES=60
SNAPSHOT_FILE=./data/trend-snapshots.json
```

개발 중 매번 새로 받으려면 `CACHE_MINUTES=0`.

4. 서버 시작

```bash
npm start
```

5. 브라우저에서 연다.

```
http://127.0.0.1:3000
```

Live Server만 켜면 `/api/trends`가 없어서 Demo 데이터로 떨어집니다. API 시크릿이 브라우저에 노출되는 구조는 아닙니다.

## 사용 흐름

1. 사이트 접속 → 전체 밈 확인
2. 4열 Grid에서 탐색
3. 국가 / 상태 / 기간 필터 사용
4. 밈 클릭 → 의미 이해
5. TikTok / Instagram / YouTube에서 실제 사례 확인

## 검색

검색을 실행하면 국가 필터가 **전체**로 바뀌고, 검색어를 YouTube·TikTok·Instagram 수집기에 전달합니다. 같은 검색은 캐시 시간 동안 API를 다시 호출하지 않습니다.

## API별 현실적인 범위

- YouTube Data API: 지역별 인기 영상과 최근 키워드 검색을 사용합니다. 공개 영상의 조회·좋아요·댓글 수는 쓸 수 있지만 공유 수는 제공되지 않습니다.
- Instagram Graph API: 프로페셔널 계정과 필요한 권한으로 해시태그의 최근 영상 미디어를 조회합니다. 다른 계정의 공개 해시태그 결과에서는 좋아요·댓글만 사용하며 조회·공유·저장은 없는 값으로 남깁니다. 본인 계정 Insights와 섞지 않습니다.
- TikTok Research API: 공개 영상의 조회·좋아요·댓글·공유·즐겨찾기 수를 사용합니다. 승인된 연구자만 공개 영상 검색을 사용할 수 있으므로, 승인된 경우에만 `TIKTOK_RESEARCH_ENABLED=true`로 설정합니다. 일반 TikTok 개발자 앱의 Client Key/Secret만으로는 동작하지 않습니다.

중국/중화권은 TikTok Research API의 `region_code=CN`과 중국어 Instagram 결과를 사용합니다. YouTube는 중국 본토 지역 인기 차트를 제공하지 않고 TikTok과 Douyin은 별도 서비스이므로, 이 구성만으로 중국 본토 전체 유행을 대표한다고 보지 않습니다. Douyin까지 포함하려면 별도의 정식 데이터 제공 계약 또는 허가된 API가 필요합니다.

API 키가 하나도 없을 때만 Demo 데이터가 표시됩니다. 키가 설정됐지만 수집 결과가 없으면 Demo로 위장하지 않고 빈 결과와 경고를 반환합니다.

## 기술

프론트는 Vanilla HTML, CSS, JavaScript입니다. 공식 API 수집과 Trend Score 계산은 Node.js 서버에서만 합니다.

## 수집·표시 구조

```text
브라우저 /api/trends
  → 플랫폼 어댑터(YouTube·TikTok·Instagram)
  → 영상 ID 중복 제거
  → 이전 수집 스냅샷과 비교
  → 해시태그·제목 유사도로 같은 밈 묶기
  → 플랫폼·국가별 백분위 점수 계산
  → 국가 비율에 맞춰 홈 피드 구성
  → 카드와 상세 영상 임베드 반환
```

API 키는 서버 환경 변수에서만 읽습니다. `server/platforms/`의 각 어댑터가 플랫폼별 응답을 공통 영상 형식으로 바꾸고, `server/services/snapshotStore.js`가 런타임 스냅샷을 저장합니다. 첫 수집에는 비교점이 없으므로 게시 후 누적 평균 속도를 쓰고, 15분 이상 지난 다음 수집부터 실제 구간 증가량을 사용합니다.

## Trend Score 계산

누적 조회수 자체보다 **지금 퍼지는 속도**를 봅니다.

```text
최근 증가 속도 = max(0, 현재 지표 - 이전 지표) / 경과 시간
가속도 = 최근 시간당 조회 증가 / 게시 후 평균 시간당 조회 증가
반응률 = 반응 수 / 조회 수
```

각 숫자는 먼저 같은 플랫폼·같은 국가 후보 안에서 0~100 백분위로 바꿉니다. 국가 후보가 3개보다 적을 때만 같은 플랫폼 전체 후보를 임시 비교군으로 씁니다. 따라서 한국 영상 10만 조회와 미국 영상 100만 조회를 직접 비교하지 않고, 각각 한국과 미국 안에서 얼마나 빠르게 커지는지 비교합니다.

플랫폼별 가중치는 다음과 같습니다.

| 플랫폼 | 사용 지표와 가중치 |
| --- | --- |
| TikTok | 조회 증가 30%, 가속도 20%, 공유 증가 15%, 공유율 15%, 댓글률 10%, 좋아요율 10% |
| YouTube | 조회 증가 40%, 가속도 25%, 좋아요율 20%, 댓글률 15% |
| Instagram | 좋아요 증가 45%, 댓글 증가 30%, 좋아요율 15%, 댓글률 10% |

최종 점수는 아래처럼 합칩니다.

```text
Trend Score = 30% 성장 속도
            + 20% 가속도
            + 15% 공유 확산
            + 15% 참여율
            + 10% 서로 다른 창작자 수
            + 10% 교차 플랫폼 확산
```

플랫폼에서 제공하지 않는 지표는 0점 처리하지 않습니다. 사용할 수 있는 항목끼리 가중치를 다시 100%로 맞춥니다. 마지막으로 서로 다른 창작자 수와 확인된 플랫폼 수에 따른 65~100% 신뢰도 계수를 적용해, 게시물 하나만 우연히 튄 경우를 낮춥니다.

## 국가 혼합 규칙

전체 홈의 기본 24칸은 한국 50%, 일본 20%, 중국/중화권 10%, 기타 국가 20% 순환 슬롯으로 구성합니다. 한 지역에 후보가 부족하면 빈칸을 만들지 않고 남은 밈 중 Trend Score가 높은 순서로 채웁니다. 국가 필터나 직접 검색을 선택하면 이 혼합 비율을 적용하지 않고 해당 결과를 그대로 보여줍니다.

국가 판정은 TikTok의 지역 코드, YouTube 요청 지역, Instagram 캡션 언어 추정 순서입니다. Instagram의 언어 추정은 정확한 위치 정보가 아니므로 UI에서도 중국 본토가 아닌 `중국/중화권`으로 표시합니다.
